# 📝 Günün Notu Uygulaması (Cross-Platform / React Native & Expo)

Herkese selam! Bu proje, daha önce yerel (Native) Android için geliştirdiğim "Günün Notu" uygulamasının, React Native ve Expo kullanılarak hem Android hem iOS'ta çalışacak şekilde (Cross-Platform) yeniden yazılmış halidir.

### 🚀 Bu Projede Ne Yaptım?
* **Arayüz Dönüşümü:** Native Android'deki XML tasarımlarını React Native'in JSX ve Flexbox mimarisine taşıdım.
* **Veri Aktarımı (Intent -> State):** Sayfalar arası veri taşıma mantığını React Navigation ve component stateleri ile güncelledim.
* **Sıfır Kurulum (Expo Snack):** Bilgisayardaki SDK veya emülatör kurulum hatalarıyla vakit kaybetmemek için projeyi tamamen bulut tabanlı çalışan **Expo Snack** ortamına entegre ettim.
